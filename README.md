# vibe-mentor

A mentor and guardrail skill for AI-assisted development (Claude Code / Claude Desktop).

Three modes:

- **Initiation**: three throwaway practice exercises for non-developers.
- **Audit**: repository health score, top-5 priorities, issue plan.
- **Mentor**: real-time checks on generated code (Git, file size, libraries, security, i18n).

The skill lives in [`vibe-mentor/`](vibe-mentor/). To use it with Claude Code, copy that folder to `.claude/skills/vibe-mentor/`.

The functional and technical specification (in French) is the `sp_cifications_...md` file.
